# NEAR Testnet setup

1. Create separate named Testnet accounts for the owner, contract, agent and demonstration vendor. Use a Testnet wallet listed in the [NEAR wallet integration docs](https://docs.near.org/web3-apps/concepts/web-login). The owner needs a wallet that supports Testnet and transaction signing.
2. Obtain test NEAR through the faucet option in [NEAR CLI](https://docs.near.org/tools/cli) or the [NEAR Faucet](https://near-faucet.io/). Give the contract account a separate operating/storage balance, for example 5 test NEAR. Give the agent test NEAR for transaction gas, and the owner test NEAR for funding and signatures.
3. Import or select the contract account in the official NEAR CLI. Run the CLI's `contract deploy` flow on **testnet**, choose the included `artifacts/paymandate.wasm`, then select **with initialization**. Call `new` in the same batch. Provide JSON of the form `{"owner_id":"your-owner.testnet","agent_id":"your-agent.testnet"}`, 60 Tgas and zero attached NEAR. Sign as the contract account after reviewing the transaction. The account IDs above are examples and need replacement.
4. In `apps/web`, run `node scripts/setup.mjs --agent-key`. It generates a separate local key if none exists and prints only the public key. In the CLI's **account → add key** flow on **testnet**, sign as the agent's administrative wallet. Grant **function-call access** to the printed public key, the contract account, only the method `execute_mandate`, and a finite allowance such as 0.5 test NEAR. Keep the agent administrative key outside the app. See [NEAR function-call keys](https://docs.near.org/protocol/accounts-contracts/access-keys).
5. Set `NEAR_TESTNET_CONTRACT` in `apps/web/.env.local`. Restart the app. Unlock the workspace and connect the configured owner's Testnet wallet. Check the owner and agent IDs displayed under **Payment contract**.
6. In **Dashboard**, fund the tracked payment balance, for example 0.25 test NEAR. Confirm the transaction in the wallet and refresh the balance. If the contract reports `TOP_UP_UNALLOCATED_STORAGE_BALANCE`, transfer extra test NEAR directly to the contract account for storage collateral.
7. Make a local copy of an example invoice and replace its labeled Recipient field with your funded Testnet vendor. Upload that copy in **Invoices**, verify the terms against the file and choose a future expiry. Approve in the owner wallet.
8. Use **Mandates** or **Security Demo** to submit the agent call. Open the explorer link after settlement and record the real contract account and transaction hashes in the verification report. For pending results, use **Activity → Check result**. Do not replay an uncertain transfer.
9. Optional Cloud analysis. Create an API key at [NEAR AI Cloud](https://cloud.near.ai/), set `NEAR_AI_API_KEY` locally, restart the app and upload a new test invoice. The API receives invoice text when Cloud is enabled. See the [Cloud quickstart](https://docs.near.ai/cloud/quickstart).

These steps require the account holder's signatures. The included project does not contain live Testnet credentials.
